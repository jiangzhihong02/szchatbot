Type: research
Status: resolved

## Question

为 demo 准备一份**精选、准确、面向香港游客**的深圳内容库，同时喂两处：
1. **Claude system prompt**（自由问答时的背景知识）；
2. **卡片数据**（预设按钮返回的路线 / 美食 / 优惠）。

需要研究并整理：

- **美食**：有代表性的深圳/广东美食与推荐区域（罗湖东门、蛇口、龙岗客家菜等），附人均价位与必点。
- **景点/路线**：适合一日/半日的路线（美食向、亲子向、文艺向），含区域、时长、适合人群。
- **优惠**：常见且稳定的优惠形态（景点亲子套票、团体票、线上购票立减、AlipayHK/WeChat Pay HK 跨境立减）——**只做示例/公开信息汇总，不得抓取小红书等平台私域内容**。
- **香港游客视角**：过关口岸、跨境交通、支付方式（AlipayHK、WeChat Pay HK、八达通、云闪付）等实用信息。

产出：一份结构化 JSON / Markdown 内容库（可作为 `src/lib/data/` 的种子），以及喂 system prompt 的精简知识段落。核心事实需注明来源。

## Answer

**产出**：`.scratch/shenzhen-travel-assistant/research/03-shenzhen-content.md`

- **路线** 7 条：羅湖老城覓食、南山親子主題樂園日、華僑城親子機動遊戲日、蛇口文藝半日、龍崗客家古鎮、東部海岸大鵬、福田 CBD 半日。已对齐 `RouteData`/`RouteStop` 型別。
- **美食** 12 条：东门小吃、云吞面烧腊、潮汕砂锅粥、卤鹅打冷、粤式早茶、蛇口海鲜、客家菜、大盆菜、光明乳鸽、沙井蚝、椰子鸡、夜市烧烤——含人均 RMB 量级、必点、区域。对齐 `FoodData`。
- **优惠** 10 条：世界之窗/欢乐谷/野生动物园/锦绣中华/湾区之光摩天轮门票、AlipayHK、WeChat Pay HK、云闪付、离境退税、观光巴士。对齐 `DealData`。另有 **8 类稳定优惠形态**表格，可直接喂规则引擎。
- **实用信息**：8 个口岸（时刻/接驳）、5 种支付方式、地铁路线价与优惠（儿童/长者免费）、重点景点票价、商圈——供 system prompt，不进卡片。
- **System prompt 段落**：约 1000 字繁体，可直接黏用。
- **来源**：约 30 条，偏官方一手（深圳政府、HK 工贸署、景点官网）；10 项未能核实项已明确标注。
- **合规**：未抓取小红书或任何登录墙内容。

**时效要点**：新皇岗口岸 **2026-10-12 06:30 开通、24 小时通关**（HK 政府新闻公报核实）——就在 3 天后，务必进 system prompt 与内容库。

**遗留（供后续票参考）**：全部票价为研究当日公开标价，正式上线前需以官方复核；跨境钱包优惠金额多为活动期数据、很可能已过期，须改写为「常见形态」或改 App 内实时查询。
