- **Ticket**：`.scratch/shenzhen-travel-assistant/issues/03-shenzhen-content-library.md`
- **Type**：research（wayfinder）
- **研究日期**：2026-10-09
- **用途**：同時餵 (1) Claude system prompt 的背景知識；(2) 卡片資料（`src/lib/data/` 種子）

- **語言**：所有 user-facing 欄位用**繁體中文**。

> ⚠️ **價格全部為「研究當日可見的公開標價」，僅供 demo 示範。**景點票價、餐廳人均、跨境優惠每季都變，正式上線前必須以官方渠道覆核。標「(2025)」者為研究時找到的最新公開年份，可能已過期。

## 0. 如何對接現有型別

現有 `src/lib/types.ts` 已定義 `RouteData` / `FoodData` / `DealData` / `DiscountItem`。本文件第 1 節的 JSON 以它們為骨幹，並**額外加了少量 demo 友善欄位**（在欄位旁以 `＋` 標示），落地時可：

- 要最小改動 → 只取型別已存在的欄位；
- 要卡片更好看 → 把 `＋` 欄位加進 `types.ts`（例如 `priceRMB`、`tags`、`transport`）。

資料流建議：`routes` / `foods` 直接餵卡片；`deals` 走 `src/lib/sources/index.ts` 的 `CuratedSource`；`practicalities`（口岸／支付／地鐵）餵 system prompt，不進卡片。
