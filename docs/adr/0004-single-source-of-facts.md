# 口岸事實只有一份來源，system prompt 由資料生成

自由問答用的 system prompt，其【口岸】段落**由 `src/lib/data/borders.ts` 生成**，不再手抄。加了口岸、改了開放時間或接駁，卡片與 LLM 兩邊同時變。

## 為什麼

原本 prompt 裡手寫了一份口岸事實。它與卡片漂移了，而且漂移是**靜默的**：

- 票 12 依「拿不到運營方確認就不寫」的原則**刻意不列皇崗**；
- 而 prompt 告訴模型「**新皇崗口岸已於 2026 年 10 月 12 日開通、提供 24 小時通關**」——那句話被寫下的時候，**那天還沒到**。

於是確定性路徑說「不知道」，自由問答說「已經開了」。**同一件事在兩條路徑上給出不同答案，其中一個是假的，而且沒有任何東西會報警。**

漂移不只這一處。改為生成之後**當場又暴露出第二處**：羅湖的高峰時段，卡片寫「避開早上 7:30–9:30」，prompt 寫「避開早上 8:00–12:00 與下午 16:00–20:00」。兩份都自以為是對的。

這正是 [ADR-0001](0001-deterministic-rules-over-llm.md) 想避免的：**確定性的事實只該有一個來源**。prompt 需要口岸事實才能回答自由提問，但「需要用到」不等於「必須再抄一份」。

## Considered Options

- **手抄兩份（現狀）**：prompt 短、直覺。代價是**兩份會漂移，而漂移不會報錯**——它只會安安靜靜地對使用者說錯話。這個代價已經付過了。
- **每次提問只注入相關的那個口岸**：prompt 更短。但旅客最常問的恰是「**哪個口岸最順**」——那是個**比較題**，模型需要全貌才答得了。
- **（採用）從 `data/borders.ts` 生成整個口岸段落**：prompt 變長（約 1000 → 2265 字，有 prompt caching 抵銷大部分成本），換來**一份真相源**。

## Consequences

- 以後**不會再有第二次**：口岸事實只住在 `data/borders.ts`，兩處渲染。
- **「不知道」是顯式選項**：生成出來的段落結尾固定帶一句——未列於上的口岸（如皇崗），不要給出具體開放時間、也不要說它已開通或何時開通。這比「沒提到」強：沒提到時模型會自己補。
- prompt 變長，每次呼叫的 token 成本上升。以 `cache_control: ephemeral` 抵銷，但仍是真的代價。
- **本 ADR 立的是原則，不是全面套用**：prompt 裡仍手抄著美食、路線、優惠、支付的事實。它們與卡片（`foods.ts` / `routes.ts` / `deals.ts` / `engine.*` 文案）同樣有漂移風險。核心原則可以推廣——**凡兩條路徑都要用的事實，只存一份，另一份生成**——但本 ADR 只把它套用在口岸上。
- 這條原則也解釋了本專案的其他決定：詞彙只有 `CONTEXT.md` 一份（見其 `_Avoid_`）、文案只有前端一份（見 [ADR-0003](0003-locale-free-dispatch.md)）。三者是同一個形狀。
